# Scene Snap Workroom preview

This repository contains an earlier standalone visual preview of the staff workroom. The unified, runnable customer/staff/CEO application now lives in the [Scene-Snap repository](https://github.com/XBren56/Scene-Snap), which includes the Python backend, SQL database, C estimator, and protected workroom routes.

Use the Scene-Snap repository as the source of truth for the working application. The CEO folder here is documentation only; this repository is public and must not contain private business records, login details, or secrets.
